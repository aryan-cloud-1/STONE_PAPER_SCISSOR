## 🎮 About the Game

**Stone Paper Scissor** is a fun, interactive command-line game where you go head-to-head against the computer in the timeless game of chance and strategy. Choose your move, outsmart the computer, and track your score across multiple rounds!

---

## ✨ Features

| Feature | Description |
|---|---|
| 🤖 **AI Opponent** | Compete against a randomly-choosing computer |
| 🏆 **Match Mode** | Set a target number of wins to decide a match winner |
| ♾️ **Endless Mode** | Play unlimited rounds without a target |
| 📊 **Live Scoreboard** | Track wins, losses, and draws in real time |
| 🔡 **Flexible Input** | Enter moves by number (`1`) or name (`stone`) |
| 🔄 **Play Again** | Instantly restart for another round after each game |

---

## 🕹️ How to Play

### Rules

```
🪨  Stone   beats  ✂️  Scissor
📄  Paper   beats  🪨  Stone
✂️  Scissor beats  📄  Paper
```

### Controls

```
1 → Stone
2 → Paper
3 → Scissor
4 → Exit
```

> You can also type the move name directly: `stone`, `paper`, `scissor`

---

## 🚀 Getting Started

### Prerequisites

- Python 3.x installed on your machine

### Run the Game

```bash
# Clone the repository
git clone https://github.com/aryan-cloud-1/STONE_PAPER_SCISSOR.git

# Navigate into the project directory
cd STONE_PAPER_SCISSOR

# Start the game
python stone_paper_scissor
```
